## Actual architecture

`cli.py` routes strict local plans (`plan.py`), SRT (`subtitles.py`), timestamped completed Step results (`timed_asr.py`), text-only Step SSE (`step_asr.py`), speech-span compiler (`rough_cut.py`), editorial fingerprint/approval (`editorial.py`), renderer (`render.py`) and external adapters (`jianying.py`, `yichen.py`, `openverse.py`). Before this change, semantic suggestions could only be imported from another process; there was no model transport, executable Agent or joined semantic-edit/render command.

The new `agent.py` owns strategy contracts and independently enforces exclusion policy. `llm.py` supplies a configurable compatible transport with explicit network/billing opt-in and cached single submission. `pipeline.py` binds media/transcript/settings hashes, persists job stages, compiles reviewed decisions through the existing renderer and supports recovery. It deliberately reuses the independent project engine rather than vendoring upstream internals.
