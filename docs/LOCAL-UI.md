# 本地剪辑工作台

在仓库环境安装后启动：

```bash
python -m pip install -e .
python -m video_clips doctor
python -m video_clips ui --workspace /path/to/your/media --port 8765
```

在浏览器打开终端打印的完整会话链接。服务只绑定 `127.0.0.1`；会话链接授予所选工作目录的操作权限，请勿分享。程序不创建云端托管站点，不需要访问其他电脑。关闭终端服务后界面不再执行新任务。

## 可执行流程

1. 点击素材库的 `＋` 或拖入视频、音频、SRT、JSON；也可以浏览所选目录中的现有文件。导入限制为每个文件 2 GiB，不覆盖原文件。
2. 选择视频预览，再选择 SRT 或已完成且带分句时间戳的 Step 文件识别 JSON。多声道结果请先用 CLI 选定声道转换为 SRT。此版本不把无时间戳文字当作字幕。
3. 在“转写与字幕”中修改文字、开始秒数或持续秒数。错误、重叠、越界时间会被后台拒绝。
4. 配置剪辑策略、目标时长、画幅、保护术语和可选本地背景音乐。音乐按成片/音频源较短的时长铺设，不自动循环、搜索或购买素材。
5. 模型模式需要完整兼容接口地址、模型 ID，并显式勾选本次调用授权；密钥从启动进程的 `VIDEO_CLIPS_MODEL_KEY` 读取。已有 Agent 决策可选择离线 JSON，完全不调用模型。离线回复必须绑定当前转写；修改字幕后需生成新的匹配回复。
6. 点击“生成剪辑并渲染”，查看排队、内容分析、计划、渲染和质量检查阶段。任务由本地单工作线程顺序执行，避免同时占满渲染资源；重复的运行中请求会合并。
7. 在“删留审核”中勾选可执行的删除建议，或取消勾选恢复片段。“按审核结果生成新版本”复用已有决策，在新任务目录重新渲染，不再调用模型，旧版本和原素材都保留。数字、保护术语和不确定内容仍受后台规则约束。
8. 点击时间线片段跳转、切换原片/成片预览，下载 MP4、SRT、时间线、审查/质量报告和剪映适配计划。剪映适配计划不是原生草稿或原生导出。

## 队列与恢复

状态、请求配置、转写和产物保存在工作目录的 `.video-clips/jobs/`；导入素材位于 `imports/`。这些文件包含本地路径和转写，应保持私密。界面启动后可以从底部列表重新打开已有任务。中断/失败任务有“恢复任务”按钮，使用原配置和模型响应缓存；不自动重投未确定计费的请求。若遗留 `.running` 或 `model.pending.json`，先确认工作进程、服务商任务和计费，再手工处理；界面不会代替用户猜测。

原片长且无转写时，自动文件-ASR提交/查询仍待实现；当前可导入外部真实时间戳结果。时间线为保留片段可视化及定位，尚不支持拖拽多视频轨、画中画、转场或关键帧。画幅采用等比缩放加边，不声称自动人脸裁切。质量检查验证结构、帧数、音视频时序和完整解码，不替代人工听看、字幕准确性与上下文审核。

## 开发验收

`python tools/smoke_demo.py --out outputs/ui-demo` 生成独立合成素材和明确标注的模型回复夹具，然后运行真实 CLI/FFmpeg。`npm ci && npx playwright install --with-deps chromium && npm run test:ui` 在云端/开发机执行浏览器联调：选择素材与字幕、离线 AI 决策、后台渲染、审核恢复、下载 MP4，以及桌面/手机布局。它不发送付费请求。GitHub CI 提供日志、实际成片、质量报告及浏览器截图。
